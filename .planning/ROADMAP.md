# Roadmap — AI Habit Quest v1

4 coarse phases, vertical-MVP mode, ≈1 week each. Each phase ends with something the user can touch.

### Phase 1: Foundation & day-1 loop
**Goal:** A new user opens the Mini App, picks a goal, sees a 7-day plan stub, and the data persists in Postgres.
**Mode:** mvp
**Requirements:** AUTH-01..04, GOAL-01..04, INFRA-01..04
**Success Criteria:**
1. `docker compose up` launches backend + web + postgres + ai-service with no errors.
2. Opening the Mini App from Telegram authenticates the user and creates a `User` row on first launch.
3. User can create one goal from a category template and immediately see a 7-day plan generated by the stub AI port.
4. Free-tier limit (1 goal) blocks a second goal with a clear Premium CTA.

### Phase 2: Tasks, gamification, reminders, i18n
**Goal:** Daily tasks drive streak and XP, the bot reminds at the user's chosen time, and the UI ships in RU and EN.
**Mode:** mvp
**Requirements:** PLAN-01..04, TASK-01..04, GAME-01..04, NOTIF-01..03, I18N-01..02
**Success Criteria:**
1. The user sees at most 3 tasks for today and can toggle done/undo.
2. Completing at least one task per day extends `streak_current`; missing a day resets it.
3. XP, level, badges visible on the Progress screen, last-7-day completion bar renders.
4. Daily reminder fires via the bot at the user's chosen time and is suppressed when all today's tasks are done.
5. UI text switches RU/EN based on `language_code` with a manual override.

### Phase 3: Monetisation & admin
**Goal:** A user can subscribe via YooKassa (trial + recurring) or Telegram Stars, an admin can see and manage subscriptions.
**Mode:** mvp
**Requirements:** PAY-01..06, ADMIN-01..04
**Success Criteria:**
1. YooKassa trial payment (1 ₽, 3 days) succeeds in test mode and the user becomes Premium for the trial window.
2. The next month's YooKassa recurring charge runs against the saved `payment_method_id` and notifies the user on failure.
3. Telegram Stars invoice for the Premium SKU opens, succeeds, and upgrades the user via the success webhook.
4. `/admin/users` (basic-auth) lists users, shows subscription status, and supports manual Premium grant/revoke.

### Phase 4: Growth — referrals, polish, launch checklist
**Goal:** Project is ready for closed beta — referral loop, error budgets, offer documents, observability basics.
**Mode:** mvp
**Requirements:** REF-01..02
**Success Criteria:**
1. Each user has a referral link; a new joining user grants the inviter 3 days of Premium (capped 30 days/month).
2. Privacy policy and public offer are reachable from the Subscription screen and the bot `/help`.
3. Critical-path metrics (signups, plan creations, task completions, paid conversions) are logged in a structured way for later analytics.
4. Bot token in `.env` has been rotated relative to anything shared during development.
