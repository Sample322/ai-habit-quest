# Геймификация и Premium — дизайн на завтра

Контекст: ядро + достижения/ранги/лидерборд уже в проде (этот заход). Ниже — как довести 5 идей до «боевого» уровня и сделать Premium реально привлекательным.

## Что уже сделано (этот заход)
- **Ранги**: уровни с именами (Новичок→Легенда), XP-прогресс до следующего уровня. `/progress.rank`.
- **Достижения**: 11 ачивок, вычисляются из статистики (всегда корректны, не «отвалятся»). `/progress.achievements`.
- **Лайв-лидерборд**: топ-20 по XP + твоё место. `/leaderboard`.
- **Premium-различие #1**: перегенерация плана — только Premium (free → апселл).
- Ревамп вкладки «Прогресс» (ранг-карта, график, ачивки, лидерборд).

## 1. Достижения — следующий уровень
Сейчас derived (без БД). Чтобы добавить «вау»:
- **Момент получения**: ловить переход «не было → есть» при toggle задачи → haptic + тост «🏆 Новое достижение: …» + анимация. (Хранить earned-set в БД через таблицу `UserBadge` или сравнивать prev/next в ответе toggle.)
- **Редкость/очки**: бронза/серебро/золото, бонус XP за получение.
- **Секретные ачивки** (показывать «???» до получения) — любопытство.
- Premium-ачивки (за мультицели, длинные серии) — статусность.

## 2. Контроль выполнения (виден прогресс к цели)
- На карточке цели: **полоса прогресса по плану** (день X из horizon) + % выполненных задач за всё время по цели.
- **Календарь-хитмап** (как GitHub) последних 30 дней по цели — наглядно «не рвётся ли цепочка».
- Еженедельный итог: «на этой неделе ты выполнил 18/21 — лучше прошлой на 12%».
- Технически: есть `DailyTask` с `doneAt` и `Plan.horizonDays` — данные есть, нужен агрегат-эндпоинт `/goals/:id/insights` + UI.

## 3. AI микро-задания (ключевая фишка вовлечения) — Premium
Идея: 1-2 раза в день ИИ подкидывает бонусное действие по теме цели за доп. XP/мини-награду.
- **Модель данных**: новая таблица `BonusTask {id,userId,goalId,title,xp,createdAt,expiresAt,doneAt}` (миграция).
- **Генерация**: расширить ai-service `/bonus-task` (вход: цель + уже сделанное) → 1 короткое «стретч»-действие. Промпт: «дай одно необязательное, но полезное действие на сегодня сверх плана, ≤80 симв».
- **Триггер**: cron (как напоминания) раз в день материализует bonus-task для активных целей Premium-пользователей; second опционально.
- **UX**: отдельная карточка «✨ Бонус от ИИ» на «Сегодня», с большей наградой (например +25 XP), сгорает к концу дня → создаёт срочность.
- **Premium-гейт**: бонус-задания только для Premium (сильный стимул подписки + реально ценно).
- Риск: зависит от стабильности бота/ИИ (генерация ок; доставка-напоминание о бонусе — через бота, упирается в RU↔Telegram).

## 4. Система ранга — глубже
- Уже есть тиры + прогресс. Добавить:
  - **Перки за уровни**: на уровне N открывается рамка аватара/титул/тема — косметика, мотивирует.
  - **Сезоны**: XP-сезон 4 недели, в конце — награда топам, мягкий сброс позиций (не XP). Держит интерес долгосрочно.
  - Визуально: бейдж ранга в шапке рядом с именем.

## 5. Рейтинг между пользователями — расширение
- Сейчас глобальный топ по XP. Добавить:
  - **Лиги** (как Duolingo): группы по ~30 человек, недельная таблица, топ-N повышаются, низ — понижаются. Сильнейший ретеншн-механик.
  - **Фильтры**: «друзья» (через рефералов/`referredBy`), «за неделю» vs «всё время».
  - Анти-чит: XP только за реальные выполнения (уже так); rate-limit на toggle (есть глобальный throttle).
  - Приватность: опция скрыть имя (показывать «Игрок#1234»).

## Premium — что реально продаёт (стратегия)
Бесплатно (крючок): 1 цель, план 7 дней, базовые ачивки/лидерборд.
**Premium (ценность):**
1. Несколько целей одновременно (есть).
2. План на 30 дней (есть).
3. Перегенерация плана ИИ (есть, этот заход).
4. **AI микро-задания** (идея 3) — главная новая ценность.
5. Восстановление серии (streak freeze) 1-2 раза/мес — против «сорвался и бросил».
6. Premium-ачивки + рамка/титул.
7. Расширенная аналитика (хитмап, недельные итоги — идея 2).
Подача: на местах, где free упирается в лимит, — мягкий апселл с конкретной выгодой (не баннер).

## Анти-абуз рефералки (заметка)
«Один и тот же человек бесконечно» — **уже невозможно**: реферал начисляется только при ПЕРВОЙ регистрации (один telegramId = одна регистрация = одна награда; самоприглашение заблокировано; кап 10/мес).
**Усиление против фейк-аккаунтов (на завтра, нужна миграция):** добавить `User.referralRewarded Boolean` и начислять инвайтеру бонус не при регистрации, а **после первого выполненного задания** приглашённым — фейкам придётся реально что-то делать.
